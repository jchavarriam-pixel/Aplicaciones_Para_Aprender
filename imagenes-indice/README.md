# Ilustraciones de las materias

Siete ilustraciones originales creadas con la herramienta integrada de generación de imágenes, una por tarjeta del índice. Mantienen un estilo infantil uniforme, fondo marfil y objetos grandes relacionados con el tema.

- [Todas las aplicaciones](todas.webp): libro, números, robot y globo.
- [Matemáticas](matematicas.webp): números, operaciones y figuras.
- [Español](espanol.webp): libro, lápiz y letras.
- [Inglés](ingles.webp): gato, libro y saludo «Hello!».
- [Estudios Sociales](sociales.webp): mapa, recorrido y brújula.
- [Ciencias y sentidos](ciencias.webp): audífonos, hoja y lupa.
- [Tecnología y lógica](tecnologia.webp): robot y bloques de programación.

Los archivos WebP conservan la composición completa de 1619 × 971 píxeles, sin recortar ni deformar. Se exportaron con calidad 90 para cargar aproximadamente 0,83 MB entre las siete imágenes. Los PNG originales de la herramienta se conservaron en su ubicación de generación.

El [conjunto exacto de prompts](prompts.json) contiene el prefijo común `base` y la descripción específica de cada imagen en `pedidos`. El prompt final de cada archivo es la concatenación de ambos textos. Se usó la herramienta integrada; no se utilizó la alternativa CLI/API.
