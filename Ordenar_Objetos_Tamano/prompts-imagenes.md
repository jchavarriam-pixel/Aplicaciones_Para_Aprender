# Imágenes de ordenar por tamaño

Seis generaciones independientes con la herramienta integrada de imágenes. Se solicitó fondo transparente y se conserva el canal alfa en las copias WebP de `imagenes/`. Cada ilustración se reutiliza en hasta seis tamaños de presentación, sin modificar el dibujo.

## Prompt común

Use case: scientific-educational. Asset: single isolated object sprite for a size-ordering activity for small children. Subject: exactly {SUBJECT}. Clean friendly children's educational pictogram, smooth thick outlines, soft three-dimensional shading, same cheerful illustration style across the set. Centered, entire object fully visible, occupying about 85% of the square canvas. Genuinely transparent background, no ground, no cast shadow, no scenery, no text, no letters or numbers, no face on inanimate objects, no extra objects. Crisp clear silhouette. The illustration will be repeated at different display sizes, so keep all details simple.
