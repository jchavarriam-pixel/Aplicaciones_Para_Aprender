# Prompts de las imágenes

Generación mediante la herramienta integrada de imágenes. Una generación independiente por cada par. Fondo blanco, sin transparencia. El resultado original de cada generación se conserva en el directorio de imágenes generadas de Codex; la aplicación utiliza copias optimizadas WebP en `imagenes/`.

## pelotas.webp

Use case: scientific-educational. Create one landscape educational comparison picture for children aged 5–10. Exactly two identical-design simple red playground balls side by side on the same baseline: a LARGE red ball on the LEFT half, a clearly SMALL red ball on the RIGHT half. Both same material, perspective and design, only size differs; small ball about 45% diameter of large. Each object centered within its own half with generous margins and a wide clear gap in middle. Clean friendly children's pictogram illustration, soft 3D shading, strong smooth outlines, pure white background. No text, numbers, arrows, frames, people, extra objects, decorations or faces. Size difference instantly obvious. Wide 3:2 composition, largest ball fully inside left half.

## Plantilla para los otros siete pares

Use case: scientific-educational. Asset: one landscape comparison picture in a coherent set for a children's large/small game. Exactly {SUBJECT}, side by side. One LARGE on LEFT half and the other SMALL on RIGHT half. Small object approximately 45% of the large object's height. Same design, color, material and perspective, only physical size differs. Both rest on the same baseline near bottom. Entire large object fully within left half and entire small object fully within right half, each centered in its own half. A wide clean central gap. Consistent clean friendly children's pictogram illustration, soft 3D shading, smooth thick outlines, pure white background. Wide 3:2 composition. No text, labels, numbers, arrows, dividers, frames, other objects, environment or decoration. Instantly clear size contrast.
